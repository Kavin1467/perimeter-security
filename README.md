# 🛡️ Perimeter Security — AI Thermal Surveillance System

> **Military-grade perimeter security surveillance system with real-time FLIR/Ironbow thermal camera computer vision, multi-sector intrusion detection, and prioritized tactical alert dispatching.**

🌐 **Live Demo:** [https://kavin1467.github.io/perimeter-security/](https://kavin1467.github.io/perimeter-security/)

---

## 🎯 Key Capabilities

- **Real-Time Thermal Computer Vision:** Processes live webcam or phone camera feeds using a FLIR Ironbow thermal lookup table (LUT) and temporal frame differencing.
- **Automated Intrusion Detection:** Detects suspicious movement across defined perimeter sectors (Alpha Perimeter, Bravo Gate, Charlie Warehouse, etc.).
- **Prioritized Alerts Engine:** Ranks events into Critical, High, and Medium severity categories with audible tactical alerts.
- **Multi-Sector Surveillance Grid:** Monitor multiple perimeter sectors concurrently with dynamic overlay reticles, timestamps, and sector statuses.
- **Mobile QR Phone Camera Linking:** Link any smartphone camera directly into the surveillance grid via QR code signaling.
- **Tactical Analytics & Event Logs:** Full historical audit trail of detected events, zone intrusions, and system uptime.
